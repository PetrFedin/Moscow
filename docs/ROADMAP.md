# Roadmap — Moscow mobile application

## P0 — цельный мобильный опыт

- структура приложения и навигация;
- каталог мест и тематических прогулок;
- карточка места с историческими состояниями;
- «Моя Москва»: сохранения, посещения, заметки;
- карта с фильтрами по теме и эпохе;
- активная прогулка с последовательностью остановок;
- офлайн-пакет маршрута;
- русский и английский интерфейс;
- базовые настройки доступности;
- событийная аналитика сквозного сценария.

### Критерий готовности P0

Пользователь без инструктажа устанавливает приложение, выбирает прогулку, проходит её, открывает истории, сохраняет место и после перезапуска видит свой прогресс.

## P1 — первая пространственная история

- паспорт источников Палат бояр Романовых;
- производство исторической 3D-модели;
- мобильный просмотр 3D;
- первая AR-привязка к реальному месту;
- fallback «тогда / сейчас» при плохом трекинге;
- пространственный звук;
- полевая матрица устройств и условий;
- вторая 3D/AR-сцена — Старый Английский двор.

### Критерий готовности P1

AR-сцена устойчиво запускается повторно в подготовленной точке на поддерживаемых устройствах, а не только демонстрируется в записанном видео.

## P2 — интерес и возвращаемость

- персональная лента «Что открыть сегодня»;
- коллекции районов, эпох и тем;
- задания на наблюдательность;
- семейный режим;
- аудиопрогулка с автоматическим продолжением между точками;
- история личных прогулок;
- локальные уведомления о новых историях рядом при согласии пользователя;
- редакционные подборки.

## P3 — VR и образовательный контур

- один законченный VR-эпизод Варварки;
- режим для музея / школы;
- образовательные задания;
- групповой режим экскурсовода;
- повторное использование тех же пространственных моделей и источников.

## P4 — городская платформа

- CMS исторического контента;
- роли исследователь / редактор / рецензент / 3D-художник;
- версия и история изменений реконструкций;
- реестр прав на архивные материалы;
- API для музеев и городских партнёров;
- масштабирование по районам;
- KPI пилота для городского заказчика.

## Что сознательно не делаем сейчас

- реконструкцию всей Москвы до проверки пилота;
- фальшивые AR-демо без точной пространственной привязки;
- регистрацию до первого полезного действия;
- социальную сеть ради социальной сети;
- десятки режимов без законченного пользовательского сценария;
- VR как отдельный продукт, не связанный с мобильным приложением.

## Очередность ближайшей разработки

1. Довести мобильный UX P0.
2. Подключить реальную карту и геопозицию.
3. Сохранение прогресса и офлайн-пакеты.
4. Полноценная пятиостановочная Варварка и production audio.
5. Полевой proof Палат Романовых без синтетических измерений.
6. Второй spatial object — Старый Английский двор — через собственную asset/metric/field authority.
7. Privacy-safe analytics полного туристического funnel.
8. PublishedSpatialPackage v1 как переносимый evidence/asset contract.
9. Только затем Quest/VR proof и минимальный production CMS.
