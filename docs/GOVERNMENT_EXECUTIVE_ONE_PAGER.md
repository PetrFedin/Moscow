# «Москва во времени» — предложение городского пилота

## Что предлагаем

Проверить на территории **Варварка — Зарядье** городской стандарт цифрового исторического объекта и туристического пути.

Это не предложение создать ещё один каталог достопримечательностей.

Проект связывает в один проверяемый контур:

`источник → права → историческое утверждение → реконструкция → версия 3D → пространственная проверка → публикация → маршрут → live data → аналитика`.

Мобильное приложение является пользовательской витриной этого контура.

## Первый пилот

**«Варварка во времени»**

Scope:

- 5 исторических точек;
- 2 spatial hero objects:
  - Палаты бояр Романовых;
  - Старый Английский двор;
- RU / EN / ZH;
- аудио, offline content, accessibility;
- 3D / AR;
- supervised usability pilot на 20–50 участниках;
- интеграционный contract для существующих городских tourism-data каналов.

## Что уже реализовано

Software-контур включает:

- PublishedSpatialPackage;
- source / rights / claims authority;
- City Heritage Studio workflow;
- generic spatial / metric / field evidence contracts;
- mobile journey;
- local-only privacy-safe analytics;
- cohort/study reporting;
- Live Destination Authority;
- provider freshness / booking handoff contracts;
- CITY PILOT government/investor demo;
- investment/scale decision authority;
- staged Government Delivery Manifest.

Web, iOS и Android exports проходят общий quality pipeline.

## Что ещё должно быть доказано реальностью

Проект **не** заявляет эти пункты завершёнными:

- Romanov physical field verification;
- independent Old English Court spatial repeatability;
- реальный visitor pilot 20–50 участников;
- formal live/provider access;
- measured production economics.

До прохождения этих gates статус field-verified / proven / investment-ready не используется.

## Что требуется от Москвы

1. Назначить профильного владельца задачи.
2. Определить площадку пилота.
3. Согласовать scope, методологию, план и acceptance.
4. Дать доступ к объектам и профильным экспертам.
5. Назначить integration owner для существующего tourism-data / RUSSPASS-контура.
6. Согласовать формат visitor pilot.
7. Определить допустимый договорный/финансовый механизм первого этапа.
8. После evidence принять отдельное решение о внедрении и масштабе.

## Что получает город

После успешного пилота город должен получить не презентацию, а пакет воспроизводимых результатов:

- два versioned heritage packages;
- source / rights / review trail;
- field evidence;
- visitor evidence;
- production workflow;
- City Heritage Studio governance;
- integration contracts;
- buyer-facing architecture;
- security/data-flow note;
- IP/handover matrix;
- operations/SLA draft;
- измеренную стоимость и срок следующего объекта;
- финальный отчёт с доказанными и недоказанными результатами.

## Как принимается решение после пилота

Пилот должен измерить:

- пространственную точность;
- повторяемость второго объекта;
- способность посетителя пройти journey без developer coaching;
- provider/integration feasibility;
- variable cost следующего verified object;
- lead time;
- developer hours / object;
- institution/operator hours / object;
- district setup / integration;
- annual operations.

На основании этих данных принимается человеческое Go / No-Go решение.

Приложение не генерирует автоматическую инвестиционную рекомендацию.

## Масштаб

`Варварка → район Москвы → городской standard → первый внешний регион → межрегиональный / федеральный слой`.

Федеральный предмет — не «московское приложение для всей России», а:

> стандарт подключения региона + verified heritage infrastructure + journey/orchestration layer.

## Первый запрос на встрече

> **Согласовать профильного владельца, площадку и формат доказательного пилота «Варварка во времени». После завершения pilot evidence отдельно принять решение о внедрении, финансировании масштабирования и подключении следующего района.**

## Важная граница

Пилотирование, внедрение, закупка, инвестиции и федеральная поддержка — разные механизмы.

Ни один из них не считается одобренным до отдельного официального решения.
