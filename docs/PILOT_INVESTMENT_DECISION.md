# Pilot Investment / Scale Decision Authority

## Purpose

The government/investor package must answer a narrow question before scale:

> do we have enough real evidence and measured economics for a human decision about the next district / deployment stage?

The software does **not** choose whether Moscow, an investor or a federal body should fund the project.

It only distinguishes:

- evidence that exists;
- evidence that is still external;
- economics that was measured;
- economics that is still unknown.

## Three decision blocks

### 1. Proof

Required before the package is decision-ready:

- Romanov genuinely field-verified;
- Old English Court genuinely verifies second-object repeatability;
- supervised Varvarka user pilot reviewed;
- formal live/provider integration agreement or equivalent provider authority.

### 2. Governance

Required:

- zero publication-rights blockers for the proposed public scope;
- security/data-flow review;
- IP and handover review;
- operations/SLA review.

### 3. Economics

All values must be measured and include a basis + evidence reference.

Required inputs:

1. next verified object variable cost;
2. next verified object production lead time;
3. developer hours per object;
4. institution/operator hours per object;
5. district shared setup cost;
6. district integration cost;
7. annual operations cost.

The current repository intentionally keeps all seven economics values unresolved until real production evidence exists.

## Why Old English Court matters economically

Romanov is the first spatial proof and therefore contains first-object learning.

Old English Court is the first meaningful unit-economics observation because it should run through the generic pipeline without Romanov-specific implementation.

For the second object, record:

- 3D/research production invoices or internal cost basis;
- rights-review work;
- measured survey cost;
- field verification cost;
- developer time;
- editor/historian/rights/technical reviewer time;
- calendar lead time;
- rework causes.

Only after this can the project defend a per-object production model.

## District arithmetic

When economics are measured, the bounded district model is:

```text
initial district delivery
= district shared setup
+ district integration
+ object count × measured variable verified-object cost
```

It also reports:

- annual operations cost;
- object production days under a sequential-only assumption;
- developer hours for N objects;
- institution/operator hours for N objects.

## What the model does not infer

It does not invent:

- procurement price;
- subsidy size;
- investor valuation;
- ROI;
- tourist-flow uplift;
- revenue;
- conversion uplift;
- parallel-production efficiency;
- inflation;
- taxes;
- financing cost;
- provider commercial terms.

Those require separate evidence and explicit assumptions.

## Decision semantics

The authority can return:

- proof ready / blocked;
- governance ready / blocked;
- economics ready / blocked;
- decision pack ready / blocked.

It intentionally does **not** return:

- GO;
- NO-GO;
- invest / do not invest;
- recommended budget.

Human decision-makers use the evidence pack to make that decision.
